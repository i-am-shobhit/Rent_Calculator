# 🏠 Hostel Expense Splitter (Python)

This project is a simple Python program that calculates how much each person needs to pay when sharing hostel expenses. It takes rent, food cost, electricity usage, and number of persons as input and divides the total expense equally. This project is beginner-friendly and helps in understanding basic Python concepts with a real-world example.

## 🔍 Overview
The script takes the following inputs:
Hostel Rent
Food Expenses
Electricity Units Consumed
Charge Per Unit
Number of Persons
It then calculates the total expense and splits it equally among all persons living in the room.

## ✨ Features
Calculate total electricity bill
Add rent, food, and electricity expenses
Divide total amount equally
Simple and beginner-friendly Python script
Real-world hostel expense calculation
